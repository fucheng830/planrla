# LLM 定时任务规格

## 目标

支持用户通过对话创建“定时启动一次 LLM 工作回合”的任务。它不是执行 shell、脚本或固定函数的程序化 crontab；每次触发都创建独立 Agent 会话，在指定项目上下文中执行自然语言 Prompt。

## 第一阶段范围

- 支持循环 Cron 任务：创建、查询、修改、删除、立即运行。
- 任务保存名称、Cron 表达式、Prompt、Provider、项目路径、权限模式和通知选项。
- 调度触发时复用现有 `cronPromptsDriver`，创建真实 app session 并调用现有 provider spawn 流程。
- 对话工具创建/修改/删除直接持久化，不增加额外审批步骤。
- 执行结果保留在独立会话，并通过现有消息盒子通知。
- 暂不把一次性日历事件和循环 LLM 任务混为一个资源。

## 非目标

- 不执行任意 shell/crontab 命令。
- 不让模型绕过现有 Agent 权限与审批机制。
- 暂不实现自然语言时间的复杂歧义消解；工具先接收标准 Cron 表达式，模型负责把明确表达转换为表达式。

## 安全边界

- 创建、修改、删除必须经过用户确认。
- 项目路径只允许现有项目路径或明确的绝对路径，沿用现有 cron API 校验。
- Provider 使用现有支持列表，不新增隐式 Provider。
