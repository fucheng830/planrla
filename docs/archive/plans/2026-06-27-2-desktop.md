# 桌面端(Electron fork claudecodeui)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans。

**Goal:** fork `siteboon/claudecodeui`(已有 server + React UI + claude-agent-sdk + electron-builder 配置,AGPL),补上未发布的 `electron/` 外壳,定制成 CloudCLI 桌面商业产品(账号登录接 cc.brainmate.cc + 内置 relay agent + 品牌),打包。

**Key finding(改变方案):** claudecodeui **本身就打算做桌面端**(package.json 有 electron 脚本 + electron-builder 配置),但 `electron/` 源码没发布。所以不是从零搭,是 **fork + 补 electron 壳 + 定制**。服务端入口 `cli.js start --port X`(express+ws+sqlite,默认 3001)。

**Architecture:** Electron 主进程 spawn 服务子进程(`node dist-server/server/cli.js start --port <空闲>`)→ BrowserWindow 加载 `http://localhost:<port>`。本地免登录用(用户自装 Claude Code);登录后启动内置 Node relay agent 连 cc.brainmate.cc(手机远程)。

**Tech Stack:** Electron 38 + electron-builder + React/Vite(前端)+ Express/better-sqlite3/ws(服务端)+ claude-agent-sdk。AGPL-3.0(open-core)。

**Fork 位置:** `D:\workspace\projects\ai\apps\cloudcli-desktop-fork`(已 clone)。

## 风险与待办
- **npm install 原生编译**:Windows 上 better-sqlite3/node-pty 可能要 VS build tools;失败则用 prebuilt 或 nvm 切 Node 版本(参考 [[013-service-env]] 教训)。
- **AGPL 合规**:整个桌面 App 必须 AGPL 开源(派生 claudecodeui);云端账号/计费是我们原创、闭源。上线前法务复核。
- **Claude Code 再分发**:不 bundle claude.exe(Anthropic 专有);要求用户自装。
- **上游同步**:锁一个 tag,尽量 patch 而非大改核心,便于跟上游。
- **工程量大**:M1-M5 是多阶段,建议一个里程碑一个 plan/会话,别一锅炖。
