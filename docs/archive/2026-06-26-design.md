# CloudCLI Desktop — 商业化改造设计

> **状态**:设计阶段(待 Archie review)。决策已对齐:C 方案 / Electron / 自建账号 / 商业模式 A / Open-core / 用户自备 Claude Code。

## 目标

把 CloudCLI 从「家端服务器 + 手机客户端」升级为**一体化桌面商业产品**:用户在 PC 上装一个 Electron 桌面端,本地跑 Claude Code(自带凭据,免费),登录账号后解锁**远程访问 / 多设备 / 手机控制**(付费,复用现有 cc.brainmate.cc 中继)。

**一句话**:带商业外壳和 SaaS 账号的桌面版 CloudCLI;本地免费,云端(远程/多设备)付费。

## 组件

### 1. 桌面 App(Electron,fork claudecodeui)
- **Main 进程**:
  - 以编程方式启动 fork 的 CloudCLI 服务(in-process,监听 localhost 随机端口),不再走 `cli.js start` CLI。
  - 探测用户自装的 Claude Code(`claude` in PATH / `~/.claude` / 官方安装目录);没有则引导安装。**绝不 bundle / 再分发 claude.exe**。
  - 登录后启动内置 **Node 版 Relay Agent**(从 `relay_agent.py` 移植,免 Python 依赖),向 cc.brainmate.cc 注册当前设备的 device token。
  - 系统托盘、自启动、自动更新(electron-updater)。
- **Renderer**:
  - 复用 claudecodeui 的 Web UI(聊天 / 会话 / git 面板)。
  - 新增「登录 / 注册 / 账号 / 订阅 / 远程访问开关」页面。
- **License**:AGPL-3.0(继承自 claudecodeui),源码公开。

### 2. 云端(扩展 cc.brainmate.cc)
- **现有保留**:Worker 鉴权 device token → `idFromName(token)` → RelayDO 透明转发。
- **新增 REST**(`/api/*`,JWT Bearer):
  - `POST /auth/signup` `{email,password}` → `{token,user}`
  - `POST /auth/login` `{email,password}` → `{token,user}`
  - `GET /auth/me` → 当前用户 + 套餐
  - `GET|POST|DELETE /devices` → 列出 / 注册(铸造 device token)/ 删除
  - `POST /billing/checkout` `{plan}` → Stripe Checkout URL
  - `POST /billing/webhook` → Stripe webhook(更新套餐)
- **Relay 准入**:device token 必须属于有效账号 + 套餐,否则 `/relay` 返回 402/403。

## 账号与数据模型(D1)

- `users(id PK, email UNIQUE, pw_hash, plan DEFAULT 'free', stripe_customer_id, created_at)`
- `devices(id PK, user_id FK, token UNIQUE, name, last_seen, created_at)`
- `subscriptions(user_id PK, plan, status, current_period_end, updated_at)`
- `usage(user_id, day, relay_req)` — 配额计数

**鉴权**:密码用 **Web Crypto PBKDF2**(Worker 原生,无需 Wasm)加盐哈希;JWT 用 Worker secret 签发。device token 用 `crypto.randomUUID()` + 前缀 `relay-`。

## 商业模式(A)

| | Free | Pro(订阅) |
|---|---|---|
| 本地 Claude Code | ✅ 免登录免费 | ✅ |
| 远程访问 / 手机控制 | ❌ 仅本地 | ✅ |
| 设备数 | —(无远程) | 无限 |
| 中继配额 | — | 高 / 无限 |
| 多设备同步 / 协同 | ❌ | ✅ |

- **本地永远免费**(用户自己的算力 + 凭据,无需登录即可用)。
- **付费点 = 云端中继 / 多设备 / 账号协同**(我们的基础设施成本)。
- 计费:Stripe Checkout + webhook,Worker 校验订阅状态放行 relay。

## 关键数据流

- **本地模式(未登录)**:Renderer → Main 内 CloudCLI 服务 → 本地 Claude Code → 流式回包。云端不参与。
- **开启远程(登录后)**:Main 铸 device token → POST /devices → 启动 Node Relay Agent(`wss://cc.brainmate.cc/relay?token=…`)→ 手机端同账号登录看到该设备 → 经中继连入桌面 → CloudCLI → claude。

## 授权与合规

- **claudecodeui = AGPL-3.0**:fork 后桌面 App 必须 AGPL 开源。采用 **Open-core**:桌面端开源(信任 + 采用率 + 合规),**云端账号/计费/中继为我们原创代码(不派生 claudecodeui),闭源商业**。
- **Claude Code binary = Anthropic 专有**:不 bundle、不分发;要求用户自装,桌面端只做 UI/编排。
- 上游同步:保留对 claudecodeui 上游的可合并性(尽量 patch 而非大改核心)。

## 与现有项目的关系

- **cloudcli-relay(cc.brainmate.cc)**:原地扩展(加 `/api/*` + D1 + Stripe),**不重写**。现有多租 DO、mux 协议保留。
- **cloudcli-android**:从「手填 device token」演进为**账号登录 → 列出账号下设备 → 一键连接**。复用本次做的多设备 UI(Device 列表 / 切换面板 / QR)。
- **relay_agent.py**:移植为 Node 版嵌入桌面端(用户无需装 Python)。0.13 的 home 场景仍可用 Python 版。

## MVP 范围(v1)

1. Electron 外壳:fork claudecodeui,本地模式跑 Claude Code(免登录)。
2. 账号注册 / 登录(邮箱密码)on cc.brainmate.cc(D1 + PBKDF2 + JWT)。
3. 「远程访问」开关:铸 device token + Node relay agent 连中继。
4. cloudcli-android:账号登录 → 列设备 → 连接(替代手填 token)。
5. Stripe 计费:**v1.1 fast-follow**(MVP 先用账号 + 远程开关,Pro/Free 用后端标志位区分;Stripe 接进来即开售)。

MVP 之外:v1 之后再做协作、托管算力(C 模式升级档)、团队/组织。

## 风险与待办

- **AGPL 边界**:确认桌面 App 的所有派生代码均 AGPL;云端不得 link 桌面侧 GPL 代码(保持原创隔离)。法务上线前再核。
- **Claude Code 探测/引导**:不同 OS(Win/Mac/Linux)探测路径要稳;探测失败要有清晰引导。
- **D1 / Worker 免费档限额**:用户量起来后需评估升档(D1 5GB、Worker 调用数)。
- **claudecodeui 上游版本锁定**:v1 锁定一个 tag,避免 fork 维护漂移。
- **二进制体积**:Electron + fork 的 server dist;claude binary 不打包,体积可控。
