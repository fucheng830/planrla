## 已知问题 / 遗留

- **前端主 chunk 2.86 MB**(gzip 868 KB):既存技术债,未做 code-splitting / manualChunks;首屏偏重。建议录新 REQ 优化。
- **release-it 无 GITHUB_TOKEN**:fallback 到 web,本次用 `gh release create` 手动补建 + 上传二进制。建议配 `GITHUB_TOKEN` 到 release-it(hooks env)以自动化。
- **husky lint-staged Windows bug**:`git apply --index null` 在局部 src/ commit 时偶发;workaround 是全量 commit 或 `--no-verify`(内容已验证)。建议升级 lint-staged 或提 issue。
- **node_modules 当前 ABI 139(electron)**:发版打包后未 sync 回 node。Web dev(`npm run dev`)前需 `npm run sync:node` 翻回 127。
- **v0.4.1 无 GitHub Release/安装包**:历史欠账(release-it 同样没 token,未补)。如需可后补。
