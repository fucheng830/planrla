## 需求

### REQ-046 后台任务管理面板 — feat
统一聚合四类后台任务(kanban / a2a / chat / agent Bash)到一个面板(侧边栏 Activity icon 入口)。每类专属卡片 + 状态(running / idle / stuck / failed / completed),支持**真 kill**(调 SDK `stopTask`,非孤儿进程)。agent Bash 解析 SDK `tool_use` events + 启发式完成态(无明确 done signal 时按 idle/stuck 超时判)。

**顺带修**:① sweeper 挂死超时(10min)只对 kanban/bash,不误杀 chat/a2a —— chat 跑中 `lastActivityAt` 不更新(stream_delta 不调 upsertChat),原逻辑误判 stuck → "chat failed stuck: no activity for 10min",实测修复;② 补 UI 入口按钮(原 subagent 实施漏接 `SidebarHeader` Activity icon)。

### REQ-047 侧边栏 Markdown 编辑器 — feat
对标 Codex(@gengdaJ 帖 2026-07-28):侧边栏直接编辑 .md,手动 + AI 辅助(选段让 agent 改,≤5s),用户不再切 Obsidian/VSCode。planrla 流程全是 .md(spec/plan/BACKLOG/release),改这些得切外部编辑器,上下文断。

**范围**:侧边栏新面板(portal,同 BackgroundTaskPanel 模式)+ .md 浏览(项目树)+ CodeMirror md 编辑(源码/预览)+ AI 选段改(复用 REQ-030/046 silent 通道 + stopTask,inline diff)+ server 文件 API(GET/PUT `/api/files`)。

### REQ-049 对话 fork — feat
对标 Codex `/fork`(app/desktop)+ `codex fork --last`(CLI):点 fork → 复制当前对话全历史 → 新 session → 自动切到新对话;**原对话完全不变**。用户跑长对话想「试另一条思路但不丢原对话」。

**实现**:server `POST /api/providers/sessions/:sessionId/fork`(`fsp.copyFile` 流式复制原 `jsonl_path` → 同目录 `<uuid>.jsonl` 副本 + DB 新行 + `jsonl_path` 指副本 + `custom_name` 加 "· fork" 后缀);`fetchHistory` 分叉(`provider_session_id IS NULL && jsonl_path 已设` → 直读副本);前端 `SidebarSessionItem` hover 操作组加 GitBranch 按钮。

### REQ-048 看板创建任务 404 — fix
`POST /api/tasks` 在模板找不到时裸报 `createTask failed: 404`,用户无法理解。三处修复:① `api.ts createTask` 读 `body.message`(对齐 parsePrd/submitReview);② `KanbanContext.createTask` 失败自动 `reloadTemplates()` 同步;③ `CreateTaskDialog` tplId 跟随 `templates[0]?.id`(避免过期 id)。后端 404 语义正确不动。

### Android 聊天空状态文案优化 — feat
空会话状态去掉大头像 `ProviderAvatarHeader`,新增"准备好使用 %1$s"(`chat_ready_prompt`)+ "Ctrl+K 搜索会话/文件/提交"(`chat_press_to_search`)提示,优化空消息 / 输入框 placeholder 文案。en / zh 同步。(无 REQ,文案微调)
