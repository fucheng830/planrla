## 已知问题 / 遗留

- **NotSigned**:exe/zip 未签名(无证书)。Azure Trusted Signing 待 phase 2(见 `docs/commercial/RELEASE_CHECKLIST.md`)。
- **wrangler 300MB 上限**:R2 publish 跳过 zip(338MB > 300MB);auto-update 不受影响(latest.yml + exe + blockmap 齐),zip 仅供 GH 手动下载。
- **worktree 共享主仓 node_modules 坑(新记)**:worktree 内跑 `npm run dev` 前,`preserver:dev` 的 sync:node 是空操作(worktree 无独立 node_modules),需先在**主 worktree** 跑 `npm run sync:node` 翻 ABI 127,否则 server:dev 撞 ABI 139 崩。
- **publish-r2 漏 scp latest.yml 坑(新记)**:本次 13 构建后只 scp 了 exe/zip/blockmap,漏 latest.yml,导致 R2 源短暂停留 0.6.2。已补 scp + 重传修复。后续 release 流程必须含 scp latest.yml。
- **SidebarContent.tsx 超 500 行基线**(670 行):REQ-024/025 均未拆,既有超标,可独立 refactor backlog。
