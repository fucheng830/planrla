## 需求

### REQ-051 Android 侧边栏 web UI 对齐 — feat
把 Android 客户端侧边栏全面对齐 web 端卡片风格,22 个 commit 覆盖:

**侧边栏对齐 web**:
- 图标 + 头部搜索框对齐 web 风格
- 项目 / 会话列表项对齐 web 卡片风格
- 空状态 + 项目展开指示器对齐 web
- planrla logo 对齐 web `/logo.svg`(PNG 资源替换 Canvas 绘制,修正位置 / 渐变)
- 头部内边距 = 状态栏高度 + 8dp(避让状态栏,修正 logo 被遮挡)
- Kimi / Zcode provider 图标补齐 + 会话行边角泄漏修复

**桌面端切换入口迁移**:从标题栏迁到侧边栏底部(方案 C / 位置 5),Material Computer 图标替 emoji。

**Kimi stream_delta**:Kimi CLI 只在 turn 结束给完整回复,客户端一次渲染整泡。切分为 `stream_delta`(~150 字符/秒)渐进输出,对齐原生流式 provider 体验。

**登录卡片填满**:ConnectScreen 登录卡片之前只占屏宽 70-80%(窄留白不协调),修复填满宽度(`d58e7e0` + `3a5250f`)—— Archie 之前报的 UI 问题。

**其他 fix**:
- `windowSoftInputMode=adjustResize`(消除键盘弹出时侧边栏底部空白)
- 会话标题含 `%` 切换崩溃
- 会话切换遍历滚动性能(直接跳底部,避免遍历全部消息)
- 压缩侧边栏搜索框高度
- 调试构建跳过自动更新弹窗

> 注:Android sidebar web UI 改造没走 spec/plan 流程(feat 分支直接 commit),本版追溯录 REQ-051。stream-text 抽取(`server/shared/stream-text.ts`,给 codex/zcode/claude 也用 stream_delta)进行中,未进本版(留 stash,下版继续)。
