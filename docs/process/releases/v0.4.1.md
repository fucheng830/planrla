## 变更摘要(1 提交,dfaf4be)
- `scripts/sync-native-abi.js`:显式 sync native 模块 ABI(`--target=electron` / `--target=node`),解决 electron-builder 内部 rebuild 不识别本机 VS C++ toolchain、静默回退 Node ABI 127 导致 packaged desktop(Electron ABI 139)崩溃
- `package.json`:`sync:electron` / `sync:node` scripts;`desktop:dist*` + `desktop:pack` 前置 `sync:electron`
- `build.npmRebuild=false`:electron-builder 信任已 sync 的 .node(不再内部 rebuild)

**工作流**:
- dev → `npm run sync:node`(Node ABI 127)
- desktop/packaged → `npm run sync:electron`(Electron ABI 139),或 `npm run desktop:dist:win`(自动前置 sync:electron)
