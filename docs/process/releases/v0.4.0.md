## 已知问题 / 遗留
- **desktop 开发模式(`npm run desktop`)better-sqlite3 ABI 不匹配**:npm install 装的 prebuilt 是系统 node(ABI 127),electron 需要 139。修复:`cd node_modules/better-sqlite3 && npx prebuild-install -r electron -t 38.8.6 --abi 139 --force`(详见 memory `planrla-desktop-native-abi`)。**打包版不受影响**(electron-builder 自己重编译)。
- 主项目 node_modules 缺 react-window 的预备(merge 后需 `npm install`),已在本版发版流程补装。
