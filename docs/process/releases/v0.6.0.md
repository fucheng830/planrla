## 已知问题 / 遗留

- **更新源(R2)未建**:auto-updater 配的 feed URL `https://updates.planrla.com/desktop` 还没有 bucket / 域名绑定。打包版启动后 silent 检测会 404 → error 事件静默(用户不点"检查更新"看不到)。**要让 feature 真正可用,必须**:① Cloudflare 建 R2 bucket `planrla-updates` + 绑 `updates.planrla.com` ② 设 `CF_ACCOUNT_ID` + `CLOUDFLARE_API_TOKEN` env ③ `npm run publish:update` 上传 v0.6.0 产物 ④ `curl https://updates.planrla.com/desktop/latest.yml` 验 200。
- **鸡生蛋**:v0.6.0 是首个含 auto-update 代码的版本,用户必须**手动装**;从 v0.6.0 起后续版本才能自动更新。
- **CSS 警告**:build 时 esbuild 报若干 "Unexpected !/{" css-syntax-error(esbuild 容忍,不阻断);疑似某组件 CSS 小语法问题,非本次引入,后续可查。
- **node_modules 现在是 ABI 139(electron)**:打包后未 sync 回 node。Web dev 前跑 `npm run dev`(prescript 会自动 sync:node 翻回 127)。
