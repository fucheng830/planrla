## 变更摘要(v0.6.0 → v0.6.1)

- **`3393d55` fix(req011): publish-r2 invokedDirectly detection + use npx wrangler**
  - `invokedDirectly` 检查的 `file://` 斜杠数不匹配(`file://${argv[1]}` 2 斜杠 vs `import.meta.url` `file:///` 3 斜杠)→ `main()` 从不执行 → `npm run publish:update` 静默退出。改用 `pathToFileURL`。
  - `wrangler` 不在 PATH(项目无直接依赖,只有 `npx wrangler` 可用)→ `execSync('wrangler ...')` ENOENT。改 `npx wrangler`。
- **`65dbfaa` fix(req011): publish-r2 skip large files >300MiB with warning (wrangler limit)**
  - `execSync` 无 try/catch → 单文件失败(如 zip 338MB 超 wrangler 300MB 上限)让整个脚本崩。改 per-file try/catch + `console.warn` 跳过,latest.yml + exe 仍能传完。

## 已知问题 / 遗留

- **blockmap 没传 R2**(v0.6.0 / v0.6.1 都没):网络瞬时 + 非 critical。后果:auto-update 走全量下载(不走 differential blockmap 增量),首次升级 249MB 全下。要支持增量更新,以后得用 R2 S3 兼容 API 上传 blockmap + 大文件。
- **zip 没传 R2**:wrangler 300MB 上限。zip 不在 NSIS auto-update feed 里(latest.yml 指向 exe),不影响自动更新;GitHub Release 提供手动下载。
- **node_modules 现在是 ABI 139(electron)**:打包后未 sync 回 node。Web dev 前跑 `npm run dev`(prescript 自动 sync:node 翻回 127)。
