## 变更摘要

- `fix(chat)`:REQ-031 spacer `overflow:clip` 裁掉消息内容溢出测量盒子的尾部(`2446ba3`/`0d70ca0`)。
  - 根因:消息内容的 trailing margin / 绝对定位子元素溢出测量盒子;virtualizer 的 `getTotalSize` 只累加 `offsetHeight`(不含 margin),浏览器却把溢出计入 `scrollHeight` → spacer 下方大片可滚空白(~948px,长会话尤其明显)。**virtualizer 全程无辜**(诊断:所有 item inflation=0)。
  - 修法:spacer div(`ChatMessagesPane.tsx:303`)加 `overflow:'clip'`。用 `clip` 而非 `hidden`:不创建滚动上下文,不破坏展开工具区的 sticky 表头。

## 验收结论

- 预检:`npm run typecheck` + `npm run build` 全过(2026-07-13)。
- Archie 在 .13(Web 端)实测:底部留白消失,最后一条消息紧贴底部;诊断坐实 virtualizer 无辜、948px 溢出在 spacer 外。
- 回归:REQ-029 翻页滚位、REQ-032 初始锚定 + 流式贴底均不涉及(本次只动 spacer 一行)。
