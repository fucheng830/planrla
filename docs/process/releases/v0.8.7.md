## 新功能

### REQ-020 A2A 双向节点(Google Agent2Agent 标准,四切片完整)

**S1 client 出站**(`c57bd7e`):3 工具 `a2a_discover`/`a2a_call`/`a2a_list` 调外部 A2A agent(纯出站)。限频 30/min + 出站脱敏(filterOutbound 5 正则)+ untrusted 标记 + asar-safe(进程内 HTTP MCP)。

**S2 server 入站**(`ddafb46`):`/api/a2a` endpoint(loopback only)接收 A2A tasks/send → 注入指定 session → spawnFns 跑 → artifacts 回复。sanitize_inbound(9 正则 prompt injection)+ per-IP 限频 20/min + 一 session 一 run。

**S3 内部协作**(`52c34b5`):`a2a_list_sessions` 工具(列 a2a_exposed session)+ sessions 表 `a2a_exposed` 白名单字段 + 侧边栏"允许 A2A 委托"开关 + S2 白名单检查。agent 自主委托(C1)。

**S4 对话派生**(`94b30d2`):`a2a_call spawn=true` signal → S2 创建新 session(sessionsService.createAppSession)+ spawnFn 跑(空 context)+ 回复。走完整 A2A 链路,session A agent 可自动派生新对话执行子任务。
