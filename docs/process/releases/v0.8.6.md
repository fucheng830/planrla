## 修复

### REQ-041 聊天翻页抖动根治
根因:`@tanstack/react-virtual` 的 `measureElement` 异步测量导致翻页两次 React commit(涌入虚高 + measure 回落),中间态被 paint → 视口剧跳(实测 scrollTop ±400~1700px)。

补偿层方案(RAF / ResizeObserver / estimate 单调化 / 减批次)全证伪(都在 commit 后跑,挡不住中间 paint)。迁移到 **virtua** `VList`(flow 布局 + delta 同帧补偿:高度变化 delta 同帧应用到 scroll offset)。删 RAF restore 循环 / measureAndTrack / overscan / topLoadLock,保留分页/搜索/滚底逻辑对接 virtua ref。

Archie electron 验收:翻页不抖 + 持续加载。
