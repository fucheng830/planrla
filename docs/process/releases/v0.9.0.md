### REQ-043 kanban goal-stop-hook(主切片)
stage 级 `/goal` 式自主落地。`StageTemplate` 加 `goalCondition` + `goalMaxTurns`(默认 300):
- agent stage 配 goalCondition → 持续工作直到**自判完成**并调 `task_complete` MCP 工具(记 `goal_completed` event + service.next 推进)
- **Stop hook 顶层 `{decision:'block', reason}`** 阻止提前停(spike 实证:顶层生效,hookSpecificOutput 不生效)
- **PostToolUse catch-all + tool_name 内判断**设 flag(spike 实证:glob `*task_complete` 不命中 MCP 全名 `mcp__server__task_complete`,`*` 不跨 `__`)
- maxTurns 耗尽 → spawnFn reject(`error_max_turns`)→ 现有 catch → service.fail(兜底复用,不新增逻辑)
- 纯后端,无 UI 改动;goalCondition 缺失 = 零回归

spike:`debug/spike-stop-hook-block.mjs`(Stop block 机制)+ `debug/spike-goal-e2e.mjs`(matcher 端到端)。
