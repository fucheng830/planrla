## 需求

### REQ-050 ZCode (Z.AI) provider — feat
新增 ZCode(Z.AI)作为 Planrla 的第 8 个 provider。Z.AI 的 GLM 系模型,通过独立 `zcode-cli.js` 桥接。全套 provider 模块:

- `server/modules/providers/list/zcode/`:provider / auth / mcp / models / skills / sessions / session-synchronizer 共 7 个 `.ts`
- `server/zcode-cli.js`:ZCode CLI 桥
- `src/components/llm-logo-provider/ZcodeLogo.tsx`:logo
- 前端 provider 列表 + skills UI 注册接线

**限制**:ZCode 不允许外部改它的 MCP 配置,因此 `session-query-mcp` / `a2a-mcp` 对 zcode 跳过(启动日志可见 `skipped for zcode`);其他 provider(claude/codex/cursor/gemini/opencode/kimi)正常注入。

> **版本说明**:ZCode 实现在 `a1e99f5`(v0.11.1 tag)之后,语义上是新功能(minor),故发 **v0.12.0** 而非补 v0.11.1 产物。v0.11.1 tag 保留为历史(无 Release/R2 产物),其 2 个 fix 随 v0.12.0 一并进 packaged。
