# 发版记录

> 每个版本一个文件 `v0.x.x.md`,放本目录。
> 执行依据:`templates/release-checklist.md`。

## 记录字段(每个 v0.x.x.md 含)
- 版本 + 日期 + 主题
- 含需求(REQ-ID + 标题)
- 验收结论摘要
- 产物链接(GitHub Release URL)
- 已知问题 / 遗留
- 回退方案
- 下版本预告

## 与 CHANGELOG.md 的区别
- `CHANGELOG.md`:release-it 按 conventional commits 自动生成(commit 维度)
- 本目录 `v0.x.x.md`:人工主题化总结(版本维度,含验收/回退)
- 两者互补,不替代。
