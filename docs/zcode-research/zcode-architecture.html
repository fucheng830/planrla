Agent 运行时心脏

  • • AgentRuntime：Ports & Deps 纯依赖注入，能力按 methods/ 目录安装
  • • TurnMachine：显式状态机，phase 枚举 + 迁移合法性校验
  • • owner/lease + CommandInbox：输入串行准入，杜绝并发写冲突
  • • Compact 会话压缩是一等公民：policy / microcompact / rounds

一码三形态

  • • 单一 zcode CLI（SEA 单二进制）：无参进 TUI，--web 起 Web+后端
  • • Desktop main 仅做窗口/进程/转发，业务状态全在运行时
  • • 手机远控复用 Host attachment，不另起 Agent 实例
  • • 协议严格类型（zcode-protocol v4）+ 运行时校验

工程治理（最值得抄）

  • • architecture-policy.yaml 声明模块边界，CI 强制执行
  • • ≤400 行/文件、禁循环依赖、禁深导入、baseline 存量豁免
  • • architecture:context 生成「模块阅读包」喂给 AI
  • • AGENTS/DESIGN/CONTEXT 三文档：AI 协作规范系统化
